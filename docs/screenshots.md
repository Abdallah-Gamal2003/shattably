# Screenshot checklist

No screenshots are claimed or fabricated. Capture these from a configured Android
device with synthetic profiles before sharing the portfolio:

| Suggested file | Screen |
|---|---|
| `screenshots/service-catalog.png` | Customer service catalog |
| `screenshots/create-request.png` | Request description, city and date range |
| `screenshots/worker-orders.png` | Worker available requests |
| `screenshots/order-offers.png` | Offers and acceptance action |
| `screenshots/profile-edit.png` | Profile editing |

Hide real emails, phone numbers, tokens and private job descriptions. Add the images
to the README only after visually reviewing them. Do not use production user data
to demonstrate the app.
